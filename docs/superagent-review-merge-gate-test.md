# PR 审查与明确合并指令测试

验证编号：`PR-REVIEW-MERGE-GATE-20261101`。

本测试用于验证由 `RACErace` 提交 PR、由 `race-dsh-superagent` 审查的处理流程。

## 验收步骤

1. 代理读取 PR 差异并完成适用的内容、范围和空白检查。
2. 检查通过后，代理对已审查的提交作出正式批准，并回复审查结果。
3. PR 保持打开，等待 `RACErace` 在同一个 PR 下明确回复“合并”。
4. 收到该指令后，代理重新检查 PR 状态及提交版本，再执行合并。
5. 提交版本发生变化时，需要重新审查并重新取得合并指令。

本测试不修改应用业务代码、依赖、配置或用户数据。Issue 的直接提交模式与本 PR 的审查后合并模式分别处理。
